Bitwarden + Bitwarden CLI

Where passwords and secrets live — never in git.

What it is

Bitwarden is a password manager: an encrypted vault for passwords, API keys, and other secrets. The Bitwarden CLI (bw) is a command-line tool that can read from that same vault from a terminal or a script, once unlocked by a human.

Why it's here

This whole setup follows one rule: no secrets in git, ever. But scripts and tools still occasionally need a real credential. Bitwarden CLI is the bridge — bw login is always run by a human typing the master password, never stored or scripted, so a compromised script can never silently drain the vault.

What you'll use it for

Pulling a specific secret into a script's environment at runtime (bw get item ...) instead of hardcoding it, and as the one place API keys, tokens, and passwords for future projects (like droppdd's eventual AI meal-planning API key) get stored.

Cheat sheet

# Unlock the vault - prompts for the master password,
# prints a session key (nothing readable is echoed)
bw unlock --raw

# Pull the latest vault state
bw sync

# Find an item by name
bw list items --search "some name"

# Get a secure note's full contents (needs the session key)
bw get item "exact item name"

# Lock the vault again when done
bw lock
