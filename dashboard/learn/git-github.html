Git + GitHub

Version control for the code, and a remote home for it.

What it is

Git is the tool that tracks every change to a project's files over time — every save is a "commit" with a record of exactly what changed and why. GitHub is a website that hosts a copy of that history online, so it's backed up and other people (or other machines) can pull it down.

Why it's here

Every project in this setup — skyrise itself, and droppdd — lives in git and is pushed to GitHub. An SSH key was generated for this host and registered with GitHub so pushing and pulling never asks for a password. The commit email is set to GitHub's private noreply address, so the real inbox never ends up in public commit history.

What you'll use it for

Every time work is saved in a project: git add, git commit, git push. On a new host, cloning a repo with git clone just works, no login prompt. Going forward, this is also how droppdd (and any future project) gets a history, backups, and eventually pull requests and CI.
