chezmoi

One source of truth for config files, across every machine.

What it is

"Dotfiles" are the config files behind your tools — fish's config.fish, tmux's tmux.conf, git's global config — named with a leading dot so they're normally hidden. chezmoi manages a single source copy of these files (in skyrise/dotfiles/) and applies it out to wherever it needs to actually live on a given machine, adjusting for differences between machines along the way.

Why it's here

There are two hosts in play: box (Linux) and a MacBook. They don't have identical file layouts or package managers, so plain symlinking wasn't enough — chezmoi was chosen over simpler options (like GNU stow) specifically because it can template around those differences from one repo instead of hand-maintaining two sets of configs.

What you'll use it for

Editing a config once and rolling it out everywhere: change dotfiles/ in the skyrise repo, then run chezmoi apply on each host to sync it. Bootstrapping a brand-new machine is a single command: 

chezmoi init --apply --source ~/Projects/skyrise/dotfiles
