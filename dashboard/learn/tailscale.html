Tailscale

A private network between your own devices — this dashboard's front door.

What it is

Tailscale creates a private mesh network (a "tailnet") between your own devices — this box, a MacBook, a phone — giving each one a stable private address it can reach the others by, without opening anything up to the public internet. tailscale serve takes it a step further: it can publish a service running on one device (like this dashboard on localhost:8787) to the rest of the tailnet over HTTPS, still private.

Why it's here

This dashboard needed to be viewable from a phone or the MacBook, but it's a personal build log with no reason to be public. Tailscale was chosen over something like a Cloudflare Tunnel specifically because the audience is "just my own devices" — that's what a tailnet is for. It's served at https://box.tail2b3f17.ts.net/, reachable only from devices signed into the same tailnet.

What you'll use it for

Checking this dashboard from a phone or the MacBook without a VPN client or exposing anything to the internet. The same pattern (systemd --user service + tailscale serve) is the template for privately sharing any other future local service — like droppdd's dev server — the same way.

Cheat sheet

# Check this device's status and tailnet peers
tailscale status

# Get this device's tailnet IP
tailscale ip -4

# Publish a local port over the tailnet (HTTPS, port 443)
tailscale serve --bg 8787

# See what's currently being served
tailscale serve status

# Stop serving / clear all serve config
tailscale serve reset

# (Re)authenticate this device
sudo tailscale up
