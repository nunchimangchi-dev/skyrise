tmux

A terminal that keeps running even after you leave.

What it is

tmux is a "terminal multiplexer" — it lets one terminal window hold multiple independent sessions, windows, and split panes, and keeps them all alive in the background even after you close the window or lose the connection.

Why it's here

box is a server you connect to remotely, not a laptop sitting on your desk. Without tmux, closing the terminal or losing SSH would kill anything running in it. With it — plus the tmux-resurrect and tmux-continuum plugins — sessions survive a disconnect and a full reboot, restoring automatically via a systemd --user service.

What you'll use it for

Reattaching to work in progress after closing a laptop lid or losing wifi (tmux attach -t main), and running a long-lived process — like droppdd's dev server — in one window while editing files in another, without either one depending on the other staying open.

Cheat sheet

# Start a new named session
tmux new -s main

# Reattach to an existing session
tmux attach -t main

# List running sessions
tmux ls

# Detach without killing it (default prefix is Ctrl-b)
<prefix> d

# Split panes
<prefix> "     # horizontal split
<prefix> %     # vertical split

# Kill a session entirely
tmux kill-session -t main
