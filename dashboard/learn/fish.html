Fish shell

The program that reads and runs the commands you type.

What it is

A shell is the program behind every terminal prompt — it's what turns typed commands like ls or git push into actions. Fish is one option (alongside bash or zsh), built around sensible defaults out of the box: syntax highlighting, autosuggestions from history, and readable tab completion.

Why it's here

Fish is now the default login shell on box (chsh -s /usr/bin/fish), with fisher as its plugin manager and two small, standard plugins added: fzf.fish for fuzzy searching and zoxide for jumping between directories by memory instead of full paths.

What you'll use it for

Literally every terminal session on this box. Day to day that means faster navigation (z projects instead of cd ~/Projects), fuzzy history/file search via fzf keybindings, and autosuggested commands as you type.
